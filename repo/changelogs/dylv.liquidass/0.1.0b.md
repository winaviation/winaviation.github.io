# 0.1.0b

0.1.0b is a massive liquid (gl)ass rewrite with both old snapshot and live capture engines gone. with more than 24k lines gone and 5k lines added.

## new engine

- replaced the old engines with a custom quartzcore and metal pipeline
- improved refraction blur tint edge warping radii and view isolation
- added light and dark tints, chromatic dispersion, adaptive specular and motion highlights

## new hosts

- alerts
- app icons (lags like hell tho)
- coversheet (lockscreen pull)
- keyboard
- spotlight search bar
- tab bars

## surface updates

- rebuilt existing surfaces for the new engine
- improved disable cleanup and stock ui restoration
- improved system ui compat and transitions

## prefs

- rebuilt the prefs ui with cleaner surface groups and quick nav
- linked all controls to the real engine defaults
- replaced manual rgb fields with light and dark color pickers
- added staged apply scoped resets and respring prompts
- added global custom controls with app exclusions

## perf and compat

- reduced idle renders extra display links and cost with lots of glass views
- improved renderer startup texture lifetime mask updates and pref caching
- added dynamic quartzcore symbol resolving and arm64e pac support
- added ios 14 through ios 17 (havent got the shader on iOS 18 to work)

## cleanup

- removed old engines, unused, unnecessary runtime code
- removed custom views for now while it gets rebuilt for the new engine, prolly will return in a later update
- removed old debug experimental and dead pref options
- merged duplicate render pref host and hook utils
- cleaned dead localization keys legacy code comments and whitespace
